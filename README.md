# Kitchen Chaos VR 🍔

Мультяшная VR-кухня в духе Overcooked прямо в браузере. Принимайте заказы, режьте,
жарьте и выдавайте блюда, пока не вышли 3 минуты. Работает на Meta Quest 2/3 и на ПК.

**Играть:** https://relase7.github.io/VRGamein/

## Управление

| | Quest | ПК |
|---|---|---|
| Взять / положить | Grip (боковая кнопка); навести луч и нажать grip — взять издалека, например с пола | ЛКМ |
| Бросить | Отпустить grip на замахе | ПКМ или Q |
| Резать / срезать донер | Взять нож, стучать им по доске или держать курок над доской / у вертела | Взять нож, навестись на доску или вертел и держать E |
| Раскатать тесто | Взять скалку и катать по доске (или держать курок) | Взять скалку, навестись на доску и держать E |
| Ходить | Левый стик — плавная ходьба | WASD |
| Поворот | Правый стик — рывком на 45° | Мышь |
| Меню / пауза | Курок по кнопкам, A/X — «Играть / Ещё раз / Продолжить», B/Y — пауза | Клик по кнопкам, Esc — пауза |

## Рецепты

| Блюдо | Что нужно | Как готовить |
|---|---|---|
| Салат | салат + помидор | нарезать на доске |
| Бургер | булка + котлета + салат | котлету — на сковороду |
| Фри | картошка | нарезать на доске, потом во фритюр |
| Чикен | 2 куриные ножки | во фритюр |
| Донер | лаваш + мясо + салат + помидор | мясо срезать с вертела (держать курок/E у вертела) |
| Пицца | тесто + сыр + помидор | тесто раскатать на доске, сыр натереть, положить сыр и помидор на тесто, поставить в печь |
| Чикен + фри | ножка + фри | |
| Биг-бургер | булка + котлета + салат + помидор | |

Новые блюда открываются по ходу раунда. Пока блюдо ни разу не выдано, на табло есть подсказка,
а над нужной станцией прыгает стрелка.
Котлета, курица, фри и пицца готовятся 6–8 секунд, потом начинают дымить и сгорают. Сгоревшее — в мусор.
Просроченный заказ: −10 очков, неправильное блюдо: −5. Быстрая выдача даёт чаевые.

## Разработка

```bash
npm install
npm run dev      # https://localhost:5173/VRGamein/
npm run build    # сборка в dist/
```

Dev-сервер запускается по HTTPS с самоподписанным сертификатом (WebXR без HTTPS не работает).
Чтобы проверить на Quest без деплоя, откройте в браузере шлема `https://<IP-компьютера>:5173/VRGamein/`
и примите предупреждение о сертификате. Добавьте `?debug` к адресу, чтобы видеть fps и draw calls.

На ПК удобно тестировать VR через расширение **Immersive Web Emulator**.

## Деплой

Каждый push в `main` собирает игру и публикует её на GitHub Pages (`.github/workflows/deploy.yml`).
Один раз нужно включить: **Settings → Pages → Source: GitHub Actions**.

## Устройство кода

```
src/
  main.ts            точка входа: рендерер, кнопка VR, игровой цикл
  game.ts            состояния игры (меню, раунд, пауза, результаты) и связка систем
  xr/vr.ts           контроллеры, телепорт, поворот рывками, вибрация
  input/             единый интерфейс «руки» + управление мышью и WASD
  world/             кухня, точки прилипания, частицы
  items/item.ts      ингредиенты, тарелки, нож и их состояния
  systems/           захват и физика, готовка, заказы, очки, подсказки
  ui/                3D-панели на canvas: заказы, таймер, меню
  audio/sfx.ts       все звуки синтезируются Web Audio, файлы не нужны
  style/toon.ts      палитра, toon-материалы, обводка, слияние геометрии
```

Модели еды и посуды — [Kenney Food Kit](https://kenney.nl) (лицензия CC0),
лежат в `public/models/`. Чего нет в наборе, собрано из других моделей Kenney (картошка, тесто, лаваш, донер).
Вся статичная кухня сливается в несколько мешей.
План развития — в [PLAN.md](PLAN.md).
