# Kitchen Chaos VR — план разработки

WebXR-игра в духе Overcooked: игрок стоит на мультяшной кухне, принимает заказы,
собирает блюда и выдаёт их на время. Один игрок, Meta Quest 2/3, запуск прямо
из браузера по ссылке с GitHub Pages.

---

## 1. Концепция

**Игровой цикл (один раунд, 3 минуты):**

1. На панели появляется заказ (например «Салат» или «Бургер»).
2. Игрок берёт ингредиенты из ящиков, режет на доске, жарит на плите.
3. Собирает блюдо на тарелке и ставит на окно выдачи.
4. Получает очки. Чем быстрее, тем больше. Просроченный заказ сгорает.
5. По истечении таймера показывается экран результатов и звёзды.

**Стиль:** low-poly, яркие цвета, toon-освещение, «наклейки» в интерфейсе,
преувеличенные анимации (предметы подпрыгивают, пар валит клубами, сгоревшая
еда дымится чёрным).

**Хаос:** короткие таймеры, одновременные заказы, еда горит если забыть её на
плите, предметы можно уронить и кидать.

## 2. Технический стек

| Часть | Выбор | Почему |
|---|---|---|
| Рендер и XR | three.js | Самая большая база примеров WebXR, полный контроль |
| Сборка | Vite + TypeScript | Быстрый dev-сервер, типизация помогает в игровой логике |
| Физика | Своя, минимальная | Захват предметов кинематический, бросок с простой гравитацией. Физический движок (Rapier) только если понадобится |
| Локомоция | Плавная ходьба левым стиком + поворот рывками | По просьбе игрока телепорт заменён ходьбой |
| Toon-шейдинг | MeshToonMaterial + обводка «вывернутой» геометрией | Пост-обработка на Quest слишком дорогая |
| Ассеты | Kenney Food Kit, Furniture Kit (CC0) + свои примитивы | Бесплатно, уже мультяшные, лёгкие |
| Звук | Web Audio через three.js PositionalAudio | Звуки привязаны к плите, доске, окну выдачи |
| Хостинг | GitHub Pages через GitHub Actions | WebXR требует HTTPS, Pages даёт его бесплатно |
| Отладка на ПК | Режим «мышь + WASD» и расширение Immersive Web Emulator | Не надевать шлем на каждую правку |

## 3. Структура репозитория

```
kitchen-chaos-vr/
  index.html
  package.json
  vite.config.ts            # base = '/<имя-репозитория>/' для GitHub Pages
  .github/workflows/
    deploy.yml              # сборка и публикация на Pages при push в main
  public/
    models/                 # .glb
    sounds/
  src/
    main.ts                 # точка входа: сцена, рендер-цикл, XR-кнопка
    xr/                     # XR-сессия, контроллеры, телепорт, снап-поворот
    input/                  # единый интерфейс: VR-контроллеры или мышь+клавиатура
    world/                  # кухня: столы, плита, доска, ящики, окно выдачи, мусорка
    items/                  # ингредиенты, тарелки, их состояния
    systems/
      grab.ts               # взять, отпустить, бросить, прилипание к поверхностям
      cooking.ts            # нарезка, жарка, сгорание
      orders.ts             # очередь заказов, рецепты, таймеры
      score.ts              # очки, звёзды, результаты
    ui/                     # 3D-панели: заказы, таймер, счёт, меню
    audio/
    style/                  # toon-материалы, палитра, обводка
  PLAN.md
  README.md
```

## 5. Риски и решения

| Риск | Что делаем |
|---|---|
| Низкий fps на Quest | С первого этапа следим за счётчиком fps, без пост-обработки и теней |
| WebXR не работает без HTTPS | Dev-сервер с самоподписанным сертификатом, Pages даёт HTTPS сам |
| Долго тестировать в шлеме | Режим ПК и эмулятор WebXR, в шлем только на проверку этапа |
| Укачивание | Поворот рывками, скорость ходьбы умеренная (1.6 м/с) |
| Нарезка ножом сложна в реализации | Запасной вариант: подержать кнопку над доской |
| Git не установлен | Ставим на этапе 0 через winget |

## 6. Определение готовности MVP

- Игра открывается по публичной ссылке GitHub Pages на Quest.
- За раунд 3 минуты можно выполнить минимум 3 заказа двух видов.
- Есть счёт, экран результатов и перезапуск.
- Ни одного падения браузера за 10 минут игры.
